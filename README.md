# 🥷 NinjaClash2D

A 2D fighting game built with Python and Pyglet. Choose your fighter and battle on different stages!

## 🎮 Features

- **4 Characters**: Shadow, Blaze, Slime, and Dino
- **3 Stages**: Stadium, Waffle Haus, and WH
- **2-Player Local Multiplayer**
- **Punch & Kick** attacks
- **Health Bars** with color indicators
- **Character Select Screen**
- **Intro Screen**

## 🎯 Controls

### Character Select
| Action | Player 1 | Player 2 |
|--------|----------|----------|
| Browse Characters | A / D | ← / → |
| Lock Character | J | 1 |
| Change Stage | S / ↓ | S / ↓ |
| Start Fight | ENTER | ENTER |

### Gameplay
| Action | Player 1 | Player 2 |
|--------|----------|----------|
| Move Left | A | ← |
| Move Right | D | → |
| Jump | W | ↑ |
| Punch | J | 1 |
| Kick | K | 2 |

## 🚀 How to Run

`pip install pyglet`
`python3 main_game.py`

## 📁 Project Structure

- main_game.py - Main game file
- background.png - Stadium background
- blue_ninja.png - Shadow sprite
- purple_ninja.png - Blaze sprite
- slime_buddy.png - Slime sprite
- robo_dino.png - Dino sprite
- stage_1.jpg - Waffle Haus background
- stage_2.jpg - WH background
- jump.wav - Jump sound effect
- hit.wav - Hit sound effect

- Python - Programming language
